P22 (job `cp-e2e-migration-p22-dcst`) converts behavior 22. In `tests/e2e/reports-push.test.ts` a real pi parent with
the command-post extension holds the home's lock and runs the push sweep on its own timer, its clock and timers sped up
by `tests/harness/time-scale.ts`. The push service is a stand-in HTTP server behind `tests/harness/fake-fetch.ts`, and
each test device decrypts what it received.
