Behavior 17, first slice. Each scenario starts `bin/cp-view` on a scratch home with its clock pinned through
`tests/harness/process-clock.ts`, and calls the viewer's HTTP routes. A tab (`tests/harness/dashboard.ts`) fetches `/`,
then runs the served app script over a linkedom DOM, and its `fetch` reaches the same viewer over real HTTP with a
same-origin browser's headers. A decision card's answer goes to the operator session's own dashboard-control server
(`startDashboardControl`, with pi's inject port recorded).

The pages are rendered without CSS layout. This slice asserts only DOM, text and HTTP, never pixels at 390 or 1440 px.
