The real pipeline runs through `CommandPost` (`startPipeline`, `advancePipeline`, `reanchorPipeline`) with mock-model
planner, gate-reviewer and implementer workers on a treehouse pool (installed in CI); classification runs through the
`cp_pipeline classify` tool a mock model calls in a real `pi`. Each control mutated `src/`, failed on the named
assertion, and passed once restored.

The pipeline diff gate runs through `advancePipeline` and `cp_review` with mock-model reviewers on a scratch repo
(`tests/e2e/pipeline-diff-gate.test.ts`). Two units stay in `tests/pipeline-retained.test.ts`; each row names why.
