P13c (job `cp-e2e-migration-p13c-egie`) continues behavior 12 in `tests/e2e/schedules.test.ts`.

Known defect, not fixed here (KD-P13c-new-session): a real `new_session` RPC in one pi process builds a fresh extension
runtime with an empty `woken` set, so an unexpanded skill anchor is offered twice. 12-10 pins today's two offers.
`tests/schedule-wake-retained.test.ts` no longer asserts one offer across a stop and start of one registration;
NC-P13b-woken's assertion went with it, and 12-10 is the consumer-visible pin of that dedupe.

NC-P13-claim stays on its retained unit. The parent reads requests and appends its claim on one path
(`appendScheduleControlLine`, no lock file), so a directory in the journal's place fails the read first; 12-5 already
uses that substitution and no chmod. No root-proof journal state is readable yet fails the append.

Retained verbatim in `tests/scheduler-retained.test.ts`: `Scheduler.tick` and `fireNow` under an injected clock set
back, jumped forward, crossing a Europe/Warsaw DST fall-back, or racing a run now. A parent reads only the system
clock and has no clock override; its 30 s tick cannot be aligned with a run_now.

Retained verbatim in `tests/schedule-runner-retained.test.ts`: `claimedRun` with a wake port that throws, and
`ScheduleRunner.sweepReported` racing a live `onReported`. Neither failure nor interleaving is inducible from a parent.

Retained verbatim in `tests/schedule-results-retained.test.ts`: `ScheduleResults.reconcile` with one run's edit refused,
and `resultOwner` with a role-admitted S1 against a stale `expanded:` marker. 12-15 loses a card by editing the closed
run record between processes, the scratch-home equivalent of a crash.

Retained verbatim in `tests/schedule-native-retained.test.ts`: `Scheduler.add`'s rollback after a failed policy write
(a directory in the journal's place fails the read first), `scheduleRunVerdict` on implement, merge, hard-stop and
undeclared-kind verdicts, and `startScheduledPipeline` replayed after a crash or started on a full run.

Retained verbatim in `tests/schedule-runs-retained.test.ts`: a `ScheduleRunStore` built inactive and two store instances
admitting into one run at once; a parent opens one active store.

Retained verbatim in `tests/schedule-self-review-retained.test.ts`: `advanceSelfReview` replayed after a crash, stopped
by an injected-clock deadline or a `:1` cap notice, and handed an anchor the parent marked expanded first.
