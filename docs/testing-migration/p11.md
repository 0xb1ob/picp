P11's first slice converts answer-delivery and checkpoint-root. The other 14 files stay `convert` / P11 for follow-on
slices. Every control is the one-line production mutation named in its row: with it applied, the named e2e case failed
on the stated assertion, and with it restored the case passed. Dropping both re-intake guards together
(`result.already` in `#queueAnswerCard` and the pending/delivered id checks in `AnswerCardOutbox.enqueue`) still
passes P11-answer, because no entry point re-intakes an accepted envelope. The two idempotence declarations that pin
those guards therefore stay verbatim, as the plan's "idempotence regressions block deletion" requires.
