P11 converts answer-delivery, checkpoint-root, artifacts, task-references, pipeline-classify-tool, task-addenda and
answer-card, and dispositions gate-replacement `retained`. P11 stopped at 116,468 bytes of
`git diff $(git merge-base HEAD origin/main)`, below the ~250 KB cap and with no blocker, because the main session
split the row; P11b took the other eight files and converted four ([p11b](p11b.md)).

A baseline row reads `deleted` when its path left the tree (the checker's rule). Units moved into a `*-retained` file
are ledgered `retained` row by row in the assertion map. P11-answer is `skip` only where treehouse is missing. CI
installs treehouse and runs it, so its mapped units stay mapped.

Every control is the production mutation named in its row: with it applied, the named e2e case failed on the stated
assertion, and with it restored the case passed. Dropping both re-intake guards together (`result.already` in
`#queueAnswerCard`, and the pending/delivered id checks in `AnswerCardOutbox.enqueue`) still passes P11-answer. No
entry point re-intakes an accepted envelope with its artifact, so the two declarations pinning those guards stay
`retained`, verbatim.
