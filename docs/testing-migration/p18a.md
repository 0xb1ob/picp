Behavior 18, first slice. Each viewer scenario starts `bin/cp-view` on a scratch home with its clock pinned through
`tests/harness/process-clock.ts` and reads the viewer's HTTP routes. P18-jobs-ui opens the served app in a
`tests/harness/dashboard.ts` tab. P18-parked runs the landing stack (`tests/e2e/landing-helpers.ts`) with its gh and git
fakes, then reads the same home through `bin/cp-view`. The status scenarios run a real pi parent with the command-post
extension and a mock model, then read `cp_status_block` results, `/status` notices and `setWidget` lines.

The pages are rendered without CSS layout. This slice asserts only DOM, text and HTTP, never pixels at 390 or 1440 px.
