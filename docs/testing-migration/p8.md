They drive a real CommandPost, real pi workers on a treehouse pool and the mock provider; pi's own retry is off, so
every provider error reaches the outer ladder. Fixed source: `c7e4bc263c2e6003966a0105e53253bbf60c392f`.

and `tests/failure-announcer.test.ts` stay whole: each keeps one assertion no public consumer reaches (below). The
other 16 behavior-04 files are untouched and stay `convert` for later P8 slices.

Each control below patches one fix back, runs only the named case and is restored before the next. Red logs and
patches are in `/home/ubuntu/.pi-command-post/state/artifacts/cp-e2e-migration-p8-g896/` (`<patch>.patch`,
