P13d (job `cp-e2e-migration-p13d-8ygx`) closes behavior 12 in `tests/e2e/schedules-p13d.test.ts`. Each migration runs
from a real parent's session start on a scratch home seeded with pre-native stores.

Known defect (KD-P13d-stop-revisions): when an open job defers the v2 import, the native migration in the same session
start saves a revision for an operator-stopped schedule. The import's retry then misses its resume check, and a stopped
or paused schedule gains one legacy and one native revision per deferred start. 12-20 asserts the two extra revisions.

Known defect (KD-P13d-tick-after-failed-import): a failed v2 import returns early from session start, but the
schedule tick still runs. The tick's native sweep then converts the schedule. 12-21 asserts that the native snapshot
holds the pre-import bytes and that no import revision was saved.

The unknown-skill add refusal is the cp_schedule parameter schema's own refusal. `Scheduler.add`'s "unknown skill" text
is not reachable from the tool.
