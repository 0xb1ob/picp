Behavior 19, first slice. Each scenario starts `bin/cp-view` on a scratch home with its clock pinned through
`tests/harness/process-clock.ts` and `CP_UPLOAD_ROOT` inside that home, then calls the viewer's HTTP routes. Sends
reach the operator session's own dashboard-control server (`startDashboardControl`, pi's ports recorded). The UI rows
open the served app in the linkedom tab of `tests/harness/dashboard.ts`, unchanged; `tests/harness/conversations.ts`
holds the shared fixtures. Two e2e files keep each under the 800-line cap. `tests/viewer-uploads-retained.test.ts` keeps the units no e2e surface
can reach: uploadRoot()'s /tmp default, writeUpload's O_EXCL, readUploadMetadata's read counts and returned map, and a
tailnet bind's own origin (the harness binds 127.0.0.1).

The pages are rendered without CSS layout. This slice asserts only DOM, text and HTTP, never pixels at 390 or 1440 px.
