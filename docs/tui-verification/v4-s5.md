## Acceptance and implementation

| Requirement | Implementation and evidence |
| --- | --- |
| D23: independent jobs wrap within the pane | `mapLayout` uses the measured graph width; a ResizeObserver reflows after a resize. The 227-job render regression fails on the original horizontal layout and passes with the fix. Mounted coverage also checks resize and observer cleanup. |
| D24: connected jobs use dependency depth | Lane-local Kahn traversal computes longest dependency depth for acyclic nodes. Existing `edgePoints` connects the resulting boxes; skipped-node, vertical and cross-lane routes are checked against every intervening job box. |
| Cycles and self-links stay bounded | Unprocessed cyclic nodes and their dependents share the deterministic wrapped remainder with independent jobs. A 229-node regression checks repeatability, bounds and edge clearance at 360/520/680/840 px pane widths. |
| Every selected node and edge survives | Mandate/history selection is unchanged. Layout tests compare position IDs to the complete selected lane membership and check hidden/visible historical jobs. Existing projection and mounted local-day/history tests remain in the focused checks. |
| Initial selection and aside | No initial dimming; selection and Clear selection work. Chromium confirms a 288 px aside separated from the graph by 24 px. Toggling history off clears an invisible selection. |
| Long text and S6 geometry | Job boxes are 124×96 px, mandate boxes 180×96 px, with 30 px row gaps. Full existing job titles remain in button titles and the selection panel; long IDs stay truncated within their boxes. The taller boxes reserve room for S6 text without changing edge routing. |
| Connected component cannot fit | A 12-job chain extends horizontally inside the graph instead of dropping or clipping nodes. Tests assert the last depth remains present. At 1200 px the three-depth visual fixture needs a 680 px canvas in its 576 px pane and scrolls inside that pane. |
| 390 px phone | All 227 job links remain present, and the final link can be scrolled into view. Page width remains 390 px with long objectives/titles. |
| Preserve evidence and composer behavior | No evidence producer, API projection, Shell, Sessions or composer changes. #101/#102 semantics and #110 height ownership are retained. |

Ordering is deterministic: preserve the existing lane/project/history order; put processed connected jobs in their dependency-depth column, preserving input order within each column; append independent jobs and the cyclic remainder in input order, row-major. Depth is deliberately local to each lane. Cross-lane relationships keep their existing routes rather than imposing a new global ordering.
