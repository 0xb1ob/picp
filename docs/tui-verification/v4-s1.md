## Browser checks

The plan's `compare.cjs` captured all 25 design/viewer pairs before and after. Each pair has matching PNG dimensions (13 phone and 12 desktop); the browser allowed GET only, redacted credential patterns and masked attachments.

At both 900 px and 1440 px, Overview's title starts at y=28 and sidebar Search at y=63. The baseline positions were y=80 and y=76. The clock has a live dot and monospace timestamp. A long heading stays to the left of the clock. Seven routes (Overview, Decisions, Jobs, Board, Map, Schedules and job detail) have no clock overlap with headings, header actions or job facts.

Sessions remains a direct child of `.shell-main`. Shift+Enter inserts an unsent newline. Escape closes More and restores focus to its opener; tapping the phone scrim closes More. There were zero mutation requests. Physical iOS keyboard testing was not performed.

## Focused verification

`npm run typecheck` and each of `viewer-more-menu.test.ts`, `viewer-palette.test.ts`, `viewer-jobs.test.ts`, `viewer-mobile-keyboard.test.ts` and `contracts-exports.test.ts` passed separately using `npm run test:one -- tests/<file>`. The new attention, menu and provider-tone checks first failed against the baseline. The jobs tests retain #101 matching-head CI fallback and #102 recorded/equivalent review evidence.

`npm run eval:contract` passed 27 scored cases. `CP_UPDATE_GOLDEN=1` regenerated the contracts export golden and intentionally requested a rerun; the normal golden check then passed. Both generated files already matched the checked-in versions.

The temporary fixture, adapted comparison script, browser assertions, metrics and full-resolution captures are in the run artifact `.pi-command-post/s1-visual/`. Only its published contact sheets enter the repository. The comparison script changes the original script's hard-coded worker import and output confinement to this worktree; its capture manifest and redaction remain intact. No pi/agent run was needed, so no agent directory, authentication or installed home was used.

S1 adds Refresh and Notifications to the existing `Icon` component because those glyphs were absent. Other page hierarchy changes belong to the plan's later slices; Sessions keeps its existing remaining-height flow for S8. The phone scrim is a sibling of the native details element and reuses the existing outside-pointer close handler.
