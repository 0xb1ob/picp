## Added public-consumer cases

All use a real parent process, RPC extension and MockProvider. The existing held-home fixture moved from the lifecycle module into `tests/harness/held-home.ts`; it still uses scratch homes/repos and a public fake `gh` executable. The merged-PR case uses a real scratch treehouse lease, a real pushed/merged git head, and the real teardown/ledger-close path. Its CI rule emits an ordinary operator notice and journals woke/done; the separate landed-job freshness check prevents an autonomous model turn. This distinction is asserted rather than forcing an impossible model request for a completed job.

The legacy-unconfirmed-key case changes only the persisted watch announcement list. The real watcher re-observes that key and the real continuation reports coalesced; no in-memory port or private state is replaced. The independent-head case commits and pushes another head, observes it in progress, and only then transitions its CI to green, so it measures two separate single-green keys rather than a two-fact batch.

The warm-cache case observes the actual resolve ruling. Issuing authority for independent work may separately wake the parent; this case does not mistake that authority wake for a resolve wake.
