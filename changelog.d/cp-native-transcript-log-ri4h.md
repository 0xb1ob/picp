- Native Claude jobs get a readable dashboard Log: the worker appends each top-level SDK message (text, tool calls, tool result text, thinking text; no signatures or init message) as pi session lines to `state/sessions/native/<job>.jsonl` (0600, 64 KiB block cap with a marker, a "resumed" entry per resumed turn), run status records `transcript_file`, `resolveSessionFile` reads it for native jobs, and it survives teardown.
