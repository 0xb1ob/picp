- Board links never refuse a report: a valid `delivery: board` envelope is always published and accepted, and one resolver (`src/viewer/board-link.ts`) builds its link and `responseReportUrl`'s — tunnel origin, the new `viewer.public_url` setting (Settings → Dashboard address → Public URL, `data/viewer.json` `public_url` as the file fallback, for a dashboard behind a reverse proxy such as Coder), the configured viewer host, the tailnet, else a relative `/boards/<slug>/` with a note naming the remedy (no more `no_url`).
