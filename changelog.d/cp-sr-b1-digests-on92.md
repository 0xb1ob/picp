- Parent digests are changed-only (S1-03): a `session_start` sends only the hidden digest types (`cp-parent-guidance`, `cp-memory`, `cp-standing-orders`, `cp-recent-work`) whose content changed since the last compaction, so a memory-only or recent-work-only change no longer repeats orders and guidance; a successful compaction still sends every available type once, and a failed send retries only the types still missing. `digestsInContext` is replaced by `changedDigests`.
