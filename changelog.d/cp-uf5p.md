- Worker commit signing (cp-uf5p): Claude CLI and Codex worker commits are now signed whenever the host's git signs, as pi workers' are. The worker reads the host's seven global signing keys and passes only them (minus any the worktree's own config sets) as GIT_CONFIG_COUNT pairs to the Claude implementer's Bash git and freeze checkpoint and to Codex's git_commit, git_merge and checkpoint; an agent-held ssh key reaches only a picp-written signer. A host that signs but cannot reach its key fails each commit with commit_signing_unavailable: <why>. /doctor gains signing.pi, signing.claude and signing.codex, warning when the worker's uid can reach the key. A host that does not sign is unchanged.
