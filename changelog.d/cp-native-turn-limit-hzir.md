- Native Claude turn limit: each native claude process now runs with an SDK turn cap of 500 (was 40); `CP_NATIVE_MAX_TURNS` still overrides it, but only with a positive integer. A run the SDK stops with `error_max_turns` records `stop: "max_turns"` and `max_turns` on its `native_run` event and a stderr line, and an unreported exit after it fails as the new class `turn_limit` ("Stopped at turn limit") instead of `crash`. Like every native failure it is never auto-recovered.
